# Leelanau Cellars Central v46

- Added unit and case dimensions/weight to the **Specs** tab of every Wine Library profile.
- Packaging data is matched from the same Distribution Wines record used for GTIN.
- Unit fields show height, width, weight (oz), and pack.
- Case fields show height, width, length, and case weight.
- Wines without a matching Distribution Wines packaging record remain visible with blank/placeholder values and a short availability note.
