- Merch/Apparel Print and Print Queue now open a standalone browser print window. The page no longer loads or contacts DYMO Connect's browser service.
- Standard 2.25 × 1.25 inch layout is the default. A Rotated 1.25 × 2.25 inch option can compensate if the printer driver turns the physical output. Each queued label gets its own page.
