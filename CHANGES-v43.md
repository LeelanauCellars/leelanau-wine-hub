# Leelanau Cellars Central v43

## Wine Library / Distribution navigation
- Simplified the Wine Library header to just **Wine Library**; removed the redundant "Wine Hub" eyebrow and descriptive sentence.
- Removed the "Browse by brand" label and the collection-helper sentence from the collection landing views.
- Removed the repeated "Collection" label from every collection tile.
- Restyled collection tiles as white cards with Leelanau blue typography, a light blue border, and a subtle light-blue hover state to reduce the amount of solid blue on screen.
- Applied the same cleaner collection-card treatment to Distribution Wines for visual consistency.

## GTIN in Wine Library
- Wine Library profiles now match each wine to its current Distribution Wines record using UPC first, then wine name/package size as a fallback.
- Added the matched **GTIN** directly after **UPC** in the Wine Library "At a glance" information.
- Added **GTIN** directly after **UPC** in the Wine Library Specs → Commerce7 / product facts section.
- GTIN remains sourced from the Distribution Wines catalog rather than being treated as an editable Commerce7 wine field.
