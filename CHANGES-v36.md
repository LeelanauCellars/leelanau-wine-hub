# Wine Hub v36

This build includes the v35 DYMO Connect direct-print path based on the supplied Small30334 Portrait DYMO project files. Printing uses the native DYMO template with PRICE, UPC, and SKU objects, including Code 128 for the exact Commerce7 UPC. It does not rely on Chrome's page orientation.

The Merch/Apparel list grid now uses flexible item width and bounded variant, price, and action columns. It fits beside the Wine Hub sidebar without the action buttons crossing over the price. Single-variant products leave the variant area empty.

To test, install and open DYMO Connect on the tasting-room computer, then open Merch/Apparel and use the printer selector. Print one label first, then queue two variants and print the batch. Physical printer output must still be verified on the local DYMO hardware.
