# v40 — Current Wine Guide redesign

- Replaces the user-facing **Staff Notes** section with **Current Wine Guide** throughout Central navigation and tasting-room controls.
- Removes the dedicated handwritten Staff Notes lines from the guide. Printed copies leave the normal page margins available for personal notes.
- Rebuilds the online guide as a clean report with columns for Wine, Specs, Flavor & Style, Vintage / Vineyard, and Price.
- Adds category filters and wine/flavor search to the online Current Wine Guide.
- Rebuilds Print Preview as a landscape report with **8 wines per page**, reducing a 43-wine guide to about **6 pages** instead of the previous 11-page four-wines-per-page layout.
- Increases information density without shrinking the primary flavor copy: wine names, flavor/style, specs, vintage context and price now have a stronger reading hierarchy.
- Keeps category color coding as a subtle navigation aid rather than using individual card layouts.
- Uses concise vintage context in the report instead of repeating generic viticulture-practice copy under every wine.
- Updates print/PDF titles and menu-management language from Staff Notes to Current Wine Guide.
